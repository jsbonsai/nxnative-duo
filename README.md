# nxnative-duo

An experimental fork of [nxnative](https://github.com/seedds/nxnative) for iPhones, tuned for the **iPhone Duo**
foldable. It is not an emulator: your game's own code is rebuilt to run on the phone. You bring your own game
files and `prod.keys` — nothing copyrighted ships here, and the tools never download games or keys.

**Not affiliated with Nintendo or any game publisher.** Use it only with games you own.

<p align="center"><img src="duo/design/img/split-fixed.png" width="300" alt="Luigi's Mansion 3 on the iPhone Duo held upright: the picture on top, the touch controls below"></p>

## How to play

### What you need

- A Mac with Apple silicon and **Xcode**, opened once so it finishes installing. The setup check tells you if your
  Xcode's Metal compiler is newer than the one this fork was tested with (Xcode 27.2).
- An iPhone and a cable (or the same Wi-Fi, once the phone has been paired by cable).
- A **free Apple ID**, signed into Xcode (Xcode › Settings › Accounts › +).
- Your own game (`.nsp` / `.xci`: base, update, DLC) and your own `prod.keys`. Newer games need newer master keys.
- About **15 GB free** per build. The first build of a game compiles its shaders: **10–40 minutes**.

### Quick start: Duo Builder

Duo Builder is the Mac app in [`duo/app`](duo/app/README.md). Build it once:

```sh
git clone <this repository> nxnative-duo
nxnative-duo/duo/app/package.sh                  # makes duo/app/build/Duo Builder.app
open "nxnative-duo/duo/app/build/Duo Builder.app"
```

1. **Setup.** The bottom bar says *Ready* or how many things are missing. The Setup sheet checks Xcode, the iOS SDK,
   the build tools, .NET, Python, the Apple ID in Xcode, the phone, your keys and the free disk space, and fixes
   what it can for you.
2. **Drop** your game files and `prod.keys` on the window. A game card appears: banner, name, version and a badge —
   *Tested with nxnative*, *another version tested*, or *new to nxnative*. A cartridge that holds two games asks
   which one; with more than one iPhone connected, you choose the phone.
3. Press **Install on iPhone** and follow the progress bar until it says done. The first time, trust the developer on the
   iPhone: Settings › General › VPN & Device Management › your Apple ID › Trust (Duo Builder reminds you).

The step-by-step version is [the quickstart](duo/quickstart.md).

#### The same from the command line

Duo Builder runs [`bin/duo`](bin/duo) for every step, so the two always agree.

```sh
bin/duo doctor                                  # what this Mac still needs
bin/duo fix python                              # fix one item (xcode-setup, ios-sdk, tools, dotnet, python, …)
bin/duo keys /path/to/prod.keys                 # remember your keys
bin/duo info Game.nsp Update.nsp                # name, version, support
bin/duo devices                                 # the iPhones this Mac can install to
bin/duo build Game.nsp Update.nsp --install     # build and install (--device UDID to pick a phone)
bin/duo build Cartridge.xci --title-id <id> --install   # one game from a two-game cartridge
bin/duo build Game.nsp --duo on --install       # Duo full screen, for games with a patch pack
bin/duo patch add|list|remove                   # Duo patch packs
bin/duo status                                  # the patch packs in use
```

## A free Apple ID's limits

- **3 apps** of your own on a phone at a time.
- Each app **expires after 7 days**; install it again to renew it (nothing is recompiled).
- **10 new app IDs per 7 days.** When those are used up, the builder reuses an app ID you already registered whose
  app is no longer on the phone.

## The picture

Every game starts in **Letterbox**: its own shape, with black bars on the Duo's wide inner screen. **Crop** and
**Stretch** are toggles in the in-game menu.

**Duo full screen** (experimental, opt-in) rebuilds the game's camera for the Duo's 1.42:1 screen, so the 3D world
fills it at the right proportions. It comes from a **Duo patch pack** keyed to one exact build of one game; if your
game's build ID does not match, the build refuses rather than guess. The only pack shipped today is for
**The Legend of Zelda: Tears of the Kingdom 1.4.3**. HUD elements look about 1.25× tall in Duo full screen.

Anyone can make and share a pack: the format and how to check one are in
[duo/patches/README.md](duo/patches/README.md#making-one); `bin/duo patch add` installs one.

## In the game

The **⚙** button at the bottom centre opens the menu: Picture (Letterbox / Crop / Stretch), Split screen, Touch
controls, Pad layout, Move Controls, Reset Layout, the engine's settings (↻ means it applies at the next start) and
Advanced. Held upright, the Duo splits the screen: the picture on top, the controls below.

New, and not yet tried by hand on a device: a layout editor. Pinch to resize one control, all controls or the
picture; move the picture; keep separate portrait and landscape layouts; set the controls' opacity; pick a photo as
the background.

From upstream: with an external display connected, the picture goes to the TV and the phone keeps the controls (not
yet tested on a device in this fork). More on controls, saves and settings: [docs/playing.md](docs/playing.md).

## Known issues

- Duo full screen: HUD elements look about 1.25× tall.
- Tears of the Kingdom can slow down inside shrines ([upstream #737](https://github.com/seedds/nxnative/issues/737)).
- Link's Awakening needs L+R on the title screen.
- Toy Story: Retro Roundup! closes when you start one of its PlayStation games, or when the main menu's live demo
  starts after about 2 minutes idle.
- Toy Story 3: video audio is distorted (possibly the dump).
- Cheats are Mac-only upstream; there are none on the iPhone.
- The layout editor and the external display have not been tested on a device in this fork yet.
