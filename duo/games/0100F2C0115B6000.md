# Tears of the Kingdom — `0100F2C0115B6000` (1.4.3)

Status: **running on the iPhone Duo, full screen, 30 fps.** First game to use the Duo
aspect path end to end.

## Device run (2026-10-30, iPhone19,4, iOS 27.2)

```
boot: env DM_ASPECT=fill, DM_PRESENT_FILL=stretch, DM_DUO_ASPECT=2853:2007
main: aspect ratio 1.4215 (DM_DUO_ASPECT), the camera takes the drawable's shape
present fill (DM_PRESENT_FILL): stretch to the canvas
frame step cap 0 → 30 fps at present 1
frame step: game time 60.03 s in 60.04 s (1.000 of real time)
timing: frame time p50 33.38 / p95 37.17 ms; footprint 2822 MiB; thermal 2
```

- **Picture:** fills 2853x2007 with no letterbox. The camera sees the wider view, so
  the world is not stretched.
- **HUD:** stretched horizontally ~1.25x (1.778 / 1.4215) — stamina wheel, text,
  button prompts, UI options. This is the known phase-2 item; the game is playable.
- **Frame rate:** 30 fps, game time = real time. `cap 0` means the launcher's frame
  rate is the game's own; 60 is selectable but thermal state is already 2 at 30.
- **First boot:** ~14 min of pipeline prebuild (20,016 pairs), archived to
  `00000.mtl4a`; later launches load it.

## Build

Built with the duo fork and `duo/duo.env`. The rewrite log carries
`duo aspect: 4 site(s) take the drawable ratio (state +0x40)` — the four 1.4.3 sites
(`0x628c74, 0xb43460, 0x1ff04f4, 0x253fbb0`) all matched.

## Next

1. **HUD squeeze** (phase 2): pre-squeeze UI draws so the present's stretch restores
   them. The reference project does this as `uw_ui_squeeze` (its
   `d2r_gfx/gfx/nvn/nvn_mtl.m:4486`): it identifies UI draws by their **vertex shader
   key** and narrows the draw by the inverse ratio, so the present's 1.25x restores it.
   For us that means a per-draw viewport/scissor transform in the replay, gated on a
   list of TotK UI vertex-shader keys (available from `shader_map.tsv`). The harder
   part is world-anchored markers and pixel-snapped positions, which the reference
   also leaves imperfect.
2. Frame rate: measure whether 60 holds with a controller and a cooler device.
