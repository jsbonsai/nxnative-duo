First game brought up without an upstream profile. Status: **boots and runs on the Mac
host**; iOS IPA builds; not yet tested on a device.

## What the game is

| | |
|---|---|
| Engine | Ubisoft's own (NVN), `enginedata/` + `final/` RomFS |

## Open items

1. **Frame pacing.** `frame interval >16.7 ms` on 149 of 300 frames, p99 33.82 ms,
   average present rate 56.9 fps. The game's own limiter or present interval is asking
   for 2 vsyncs part of the time. Try `fps_target 60` + `present_interval display`
   (as Luigi's Mansion 3 uses) and compare.
2. **Aspect sites (Duo).** Unknown for this engine. Use `duo/DESIGN.md`: find `fdiv`
   / `ldr` sites feeding the projection and the viewport division, then add a row to
   `duo/research/games.tsv`. Until then the Duo build is letterboxed.
3. **Online services.** 666 imports are new relative to Mario, including
   `nn::socket` (45), `nn::ldn` (17), `nn::web` (10), `nn::nifm` (10), `nn::friends`
   (7). The game is playable offline; if any of these is fatal at startup the log will
   name the call.
4. **Memory values** are still the survey's guess (3,328 MB heap region); the Mac run
   did not need a correction, so they stay until something fails.
